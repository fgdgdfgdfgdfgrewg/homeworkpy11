# Магазин электроники и товаров

Проект реализует систему учета товаров для интернет-магазина с использованием ООП в Python.

## Структура проекта
project_root/
├── src/
│ ├── init.py
│ ├── product.py # Базовые классы товаров
│ └── category.py # Классы категорий
├── tests/
│ ├── test_product.py
│ └── test_category.py
├── main.py # Пример использования
├── requirements.txt
└── README.md

## Основные классы

### Базовые классы

1. `BaseProduct` (абстрактный класс):
   - Определяет обязательные свойства для всех продуктов
   - Требует реализации свойств: name, description, price, quantity

2. `CreationLoggerMixin` (миксин):
   - Логирует создание объектов
   - Выводит информацию о классе и параметрах создания

### Классы продуктов

1. `Product` (базовый класс товара):
   - Наследует от `BaseProduct` и `CreationLoggerMixin`
   - Реализует базовые свойства товара
   - Включает валидацию цены и количества
   - Поддерживает операцию сложения (по общей стоимости)

2. `Smartphone` (наследник `Product`):
   - Добавляет специфичные свойства:
     - Эффективность
     - Модель
     - Объем памяти
     - Цвет

3. `LawnGrass` (наследник `Product`):
   - Добавляет свойства:
     - Страна-производитель
     - Срок прорастания
     - Цвет

### Класс Category

- Управляет коллекцией товаров
- Содержит счетчик общего количества товаров
- Включает валидацию при добавлении товаров
